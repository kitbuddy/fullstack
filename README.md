# Fullstack Demo

This repository contains a small full‑stack sample: a Spring Boot backend (backend/) and an Angular frontend (client/demo/).

Quick start

1. Start the backend (dev):
   cd backend && ./mvnw spring-boot:run

2. Start the frontend (dev) in a separate terminal:
   cd client/demo && npm ci && npm start
